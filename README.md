A multi-game suite featuring interactive 3D WebGL experiences and physics-based mini-games. Includes a full Antigravity action game, a 3D racing simulator with custom 3D vehicle assets (car.obj), and an interactive portfolio showcase.

---

## Included Games and Modules

1. Antigravity Game (antigravity-game/):
   - Modern TypeScript and Vite game engine.
   - Modular architecture: EngineManager, PhysicsManager, PlayerCar, and Pedestrian AI entities.
2. 3D Racing Simulator (racing-game.html):
   - High-speed 3D driving game powered by custom 3D mesh assets (car.obj).
   - Dynamic track generation, drift handling, and speed gauges.
3. Interactive Gamified Portfolio (portfolio.html):
   - Retro arcade style interactive developer showcase.

---

## Getting Started

### Play Antigravity Game:
```bash
cd antigravity-game
npm install
npm run dev
```

### Play 3D Racing Game:
Open racing-game.html directly in any modern browser with WebGL support.
